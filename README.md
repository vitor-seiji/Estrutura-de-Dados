# Estrutura de Dados

Repositório dedicado à implementação, estudos e resolução de exercícios sobre **Estruturas de Dados**. O objetivo principal é consolidar os conceitos fundamentais de Ciência da Computação através de código prático.

---

## Conteúdo do Repositório

Aqui você encontrará implementações clássicas de estruturas de dados e algoritmos relacionados:

- [x] **Listas Lineares** (Listas Sequenciais e Encadeadas)
- [x] **Pilhas (Stacks)** (`LIFO - Last In, First Out`)
- [x] **Filas (Queues)** (`FIFO - First In, First Out`)
- [x] **Árvores (Trees)** (Árvores Binárias, Binárias de Busca, etc.)
- [x] **Grafos (Graphs)** *(Conceitos e percursos)*
- [x] **Algoritmos de Ordenação e Busca**
